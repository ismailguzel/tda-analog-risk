# Results

Shipped outputs of the final analysis. All files are produced from the frozen
panel `data/panel_published.csv.gz` under the protocol in
`revision_config/revision_protocol.json`, and every file below is hashed in
`provenance/result_hash_manifest.sha256`. Exclusion radii are 0, 125, and 250
trading days; the locked topology configuration is `topology_l250_k100`.

`./scripts/reproduce_final.sh --verify-existing` checks these files;
`./scripts/reproduce_final.sh --full` regenerates them.

## `final_validation/` — blocked validation (2012–2014)

Produced by `scripts/run_revision_validation.py`.

| File | Contents |
|---|---|
| `all_configurations.parquet` | Daily validation forecasts for every prespecified candidate |
| `validation_fold_summary.csv` | Per-candidate, per-fold pinball loss, exceedance rate, and run time |
| `selection_stability.csv` | Rank of each candidate by fold, with mean, worst, and dispersion of ranks |
| `topology_window_sensitivity.csv` | Best k for each window length L = 60, 125, 250 (`scripts/build_window_sensitivity_table.py`) |
| `topology_homology_ablation.csv` | Validation folds for the H0-only and H0+H1 landscape variants (see Notes) |

## `final_evaluation/` — locked evaluation (2015–2026)

Produced by `scripts/run_locked_evaluation.py`.

| File | Contents |
|---|---|
| `forecasts_radius{0,125,250}.parquet` | Daily VaR(0.99), VaR(0.975), and ES(0.975) forecasts for the 13 finalist families at each radius; radii 125 and 250 add the matching gap-HS benchmark |
| `model_summary_radius{0,125,250}.csv` | Mean pinball loss, exceedance rate, and mean forecast levels per family |

## `final_nulls/` — history-only null controls

Produced by `scripts/run_final_nulls.py` (draws generated by `scripts/run_repeated_nulls.py`).
Two controls: topology history-feature permutation and uniform random retrieval.

| File | Contents |
|---|---|
| `main_null_draws.parquet` | 500 draws per control and radius on the evaluation period |
| `main_null_summary.csv` | Distribution of null losses per control and radius |
| `randomization_tests.csv` | Randomization p-values of the locked topology rule against each control, all radii |
| `k_sensitivity_draws.parquet` | Validation k-sensitivity: 250 draws per control, radius (0, 125), and k |
| `k_sensitivity_summary.csv` | Summary of the k-sensitivity draws |
| `null_run_metadata.json` | Design, seeds, and construction of the null runs |

## `final_inference/` — paired tests, model confidence sets, backtests

Produced by `scripts/run_final_inference.py`; the MCS files by `scripts/run_corrected_mcs.py`.

| File | Contents |
|---|---|
| `paired_primary.csv` | Topology-minus-comparator VaR(0.99) pinball differences: Diebold–Mariano and block-bootstrap intervals |
| `paired_secondary.csv` | The same for the same-level FZ0 score of (VaR, ES) at 0.975 |
| `mcs_primary_radius_specific.csv` | Radius-specific Hansen–Lunde–Nason MCS on pinball loss |
| `mcs_secondary_radius_specific.csv` | Radius-specific MCS on the FZ0 score |
| `mcs_elimination_order_pvalues.csv` | Elimination order and MCS p-values for both loss families |
| `mcs_membership_summary.csv` | Retained models per radius and loss family |
| `var99_backtests.csv` | Kupiec and Christoffersen backtests for VaR(0.99) |
| `var_es975_backtests.csv` | Mean FZ0 score at 0.975 with intervals |
| `es_block_bootstrap.csv` | Acerbi–Székely ES backtest with block-bootstrap p-values |
| `duration_diagnostic.csv` | Duration-based independence diagnostic for exceedances |

## `final_diagnostics/` — exclusion and retrieval diagnostics

Produced by `scripts/run_final_diagnostics.py`; the cutoff-tie file by `scripts/check_cutoff_ties.py`.

| File | Contents |
|---|---|
| `exclusion_comparison.csv` | Change in loss and forecast levels from radius 0 to radius 125 |
| `gap_hs_comparison.csv` | Historical simulation with a matching gap, as a recency benchmark |
| `neighbor_age.csv` | Age distribution of retrieved analogs |
| `neighbor_overlap.csv` | Jaccard overlap of neighbor sets between retrieval rules |
| `cutoff_tie_diagnostic.csv` | Exact and near ties at the k-th retrieval distance |

## `posthoc_diagnostics/` — post hoc mechanism diagnostics

Produced by `scripts/run_posthoc_diagnostics.py`. These were designed after
the main results and are reported as post hoc.

| File | Contents |
|---|---|
| `recency_matched_draws.csv` | 500 draws of a benchmark matching the age profile of the topology neighbors |
| `recency_matched_summary.csv` | Topology against the recency-matched benchmark |
| `topology_neighbor_recency.csv` | Recency profile of the topology neighbors |
| `temporal_shuffle_window_detail.csv` | Landscape distances under within-window order shuffling, 100 windows |
| `temporal_shuffle_summary.csv` | Summary of the temporal-shuffle diagnostic |

## Notes

- `final_validation/topology_homology_ablation.csv` has no generating script in
  this repository. Its configurations are registered in
  `revision_config/diagnostic_candidate_registry.csv`, and the feature modes
  are implemented in `tda_risk/topology.py`.
